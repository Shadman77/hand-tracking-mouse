# 🖐️ Hand Tracking Mouse

Control your computer’s mouse using only your hand gestures!  
This project uses **MediaPipe** and **OpenCV** to track your hand movements in real time and move the cursor accordingly.

---

## 🚀 Features

- 🖱️ Real-time hand tracking using your webcam  
- ✋ Cursor movement controlled by hand position  
- 👆 Click actions using finger gestures  
- 💻 Lightweight and easy to set up  

---

## 🧩 Requirements

- **Python:** 3.12
  ⚠️ *MediaPipe currently doesn’t support Python 3.12+ (including 3.14).*  
  If you’re on a newer version, consider downgrading to 3.10 or 3.11.

---

## ⚙️ Setup

Clone the repository:

```bash
git clone https://github.com/Shadman77/hand-tracking-mouse.git
cd hand-tracking-mouse
```

Install packages:

```bash
pip install -r requirements.txt
```
